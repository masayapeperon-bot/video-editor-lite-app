## テロップ設定

### スタイル
- **1行最大文字数**: 24文字（厳守）
- **1ページ最大行数**: 3行
- **フォント**: `"Noto Sans JP", "Hiragino Kaku Gothic ProN", "Yu Gothic", sans-serif`
- **フォントサイズ**: 64px
- **フォントウェイト**: 900
- **文字色**: `#ffffff`
- **letterSpacing**: `0.05em`
- **lineHeight**: 1.4
- **whiteSpace**: `nowrap`
- **テキスト縁取り**: 3px 黒 text-shadow（8方向 + ドロップシャドウ）
- **背景帯**: `rgba(0, 0, 0, 0.75)`、padding `32px 60px`、minHeight `200px`
- **ページ切替時フェードイン**: なし（即時表示）

### テロップ分割ロジック（重要）

テキストが長い場合、時間で分割して順番に表示する。分割の手順:

1. **文単位で分割**: `。` `！` `？` `」`（引用外）の境界で文を区切り、意味のまとまりを保つ
2. **文をページに詰める**: 1ページ最大72文字（24×3行）に収まるよう文をグリーディに詰める
3. **ページ内2行分割**: 分割位置の探索範囲を `[textLen - 24, 24]` に制限し、**両行が24文字以下になることを数学的に保証**する
4. **分割位置の優先度**（スコアが小さいほど優先）:
   - `」` の直後（優先度1）
   - `「` の直前（優先度2）
   - `。` `！` `？` の直後（優先度3）
   - `、` の直後（優先度4）
   - 上記以外はページ中央付近（優先度10）
5. 長い文（48文字超）は `、` の位置で分割してからページに詰める

### やってはいけないこと
- 全テキストを機械的にN文字ずつ切る → 文が途中で切れて「を」「た。」等の断片が表示される
- 行の最大文字数を強制しない分割 → テロップが画面からはみ出す
- カギ括弧「」の中での改行 → セリフが不自然に分断される

## Ken Burns エフェクト（画像アニメーション）

シーンごとにモーションを自動割り当て。シーン表示時間全体で progress 0→1 で進行。

### モーションサイクル（シーン順に繰り返し）
`zoomIn → panLeft → zoomOut → panRight → panUp → zoomIn → panDown → zoomOut`

### 各モーションのパラメータ
| モーション | transform |
|-----------|-----------|
| zoomIn | `scale(1.0 → 1.3)` |
| zoomOut | `scale(1.3 → 1.0)` |
| panLeft | `scale(1.2) translateX(5% → -5%)` |
| panRight | `scale(1.2) translateX(-5% → 5%)` |
| panUp | `scale(1.2) translateY(5% → -5%)` |
| panDown | `scale(1.2) translateY(-5% → 5%)` |

## 音声設定（確定版）
- **全チャンネル共通**: ElevenLabs voice `itsuki`（Voice ID: `oAlEJuW30knHWhA6cF0e`）
- **モデル**: `eleven_v3`
- **エンドポイント**: `/with-timestamps`（pageSwitchTimes算出に使用）
- **speed設定**: なし（デフォルト1.0）
- **音声加工**: 末尾0.05秒フェードアウトのみ（ffmpeg afade）
- **トリミング**: なし（APIの生音声をそのまま使用）
- **シーン尺**: 音声長 + 0.5秒（build-scenes.tsで設定）

### pronunciation.jsonの必須設定
- `"。": "、"` — 句点を読点として送ることで句点後の間を短縮（全プロジェクト共通で推奨）

### pageSwitchTimesの算出ルール（重要）
- `apiText`（発音置換済みテキスト）でalignment検索する
- 境界文字と**同じタイムスタンプを持つ文字はスキップ**し、より後のタイムスタンプを持つ最初の文字を使う
- 理由: ElevenLabsは読点と直後の文字に同じタイムスタンプを返すことがあるため

## 音声生成フロー（毎回の手順）

1. `generate-audio.ts` で音声生成（pronunciation.jsonが自動適用される）
2. `build-scenes.ts` で scenes.json を更新

```bash
npx tsx scripts/generate-audio.ts --project <作品フォルダパス>
npx tsx scripts/build-scenes.ts --project <作品フォルダパス>
```

## プロジェクト構成
- 台本の空行区切り = 1シーン = 1画像 の1:1対応
- 画像ファイル命名: `{パート}_scene_{番号}_{説明}.png`（例: `起_scene_01_冒頭フック.png`）
- 音声ファイル命名: `scene_{3桁連番}.mp3`（例: `scene_001.mp3`）
- Remotion staticFile 用パス: `images/{ファイル名}`, `audio/{ファイル名}`
